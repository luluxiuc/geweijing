# 歌未竟

> 久有凌云志，重上井冈山。——纪念毛泽东同志逝世五十周年（1976—2026）

「歌未竟」——取自《贺新郎·读史》"歌未竟，东方白"。本站以诗词、文章、影像与声音，重读一段记忆。

## 网站内容

- **诗词集**：67 篇目，全配白话译文、精选名句，可按年代/关键词浏览
- **十大名篇赏析**：革命视角的赏析 + 学习提示
- **文章集**：《毛泽东选集》一至五卷精选 47 篇全文（中文马克思主义文库转录，待校）
- **他人之眼**：斯诺、斯特朗、黄炎培、索尔兹伯里的亲历实录节选
- **平生足迹**：1910—1976 生平叙事（11 章）
- **诗词巡礼**：21 站沉浸式展播（单一总音频驱动）
- **图库**：公有领域/自由许可历史照片

## 技术

- 静态多页应用（Vite MPA），桌面 `/d/` 与手机 `/m/` 独立设计，根页按设备自动跳转
- 内容驱动：素材目录（Markdown）→ 构建脚本 → JSON
- 字体：霞鹜文楷（LXGW WenKai，CDN 非阻塞加载）
- 跨页转场：CSS View Transitions（不支持时自动降级）

## 本地构建

```bash
cd site
npm install
npm run build   # 产出 site/dist
npm run preview # 本地预览 http://localhost:4173
```

## 添加内容

素材放在 `素材/` 目录（`文字/诗词`、`文字/文章`、`文字/赏析`、`文字/忆念`、`文字/生平`、`图片`、`音频`），按既有 Markdown 格式添加后运行 `npm run build` 即自动入站。

## 部署

Cloudflare Pages（Git 集成）：仓库根目录，构建命令 `cd site && npm ci && npm run build`，输出目录 `site/dist`。
