# 图片板块

## 来源与版权原则

| 类型 | 是否可用 | 处理方式 |
|---|---|---|
| 官方发布/公开报道（人民网、新华社、求是网、共产党员网等） | ✅ | 逐张标注来源，页面上标注"来源：XXX" |
| 公有领域（Wikimedia Commons 标记 PD、1949年前出版且无版权续存等） | ✅ | 直接使用，标注公版 |
| 版权不明/需授权（商业图库、报刊水印图） | ⚠️ 不建议 | 仅作参考，不下载入库 |

## 文件命名

`内容_来源.jpg`，如 `开国大典_新华社.jpg`、`沁园春雪手迹_人民网.jpg`

## 候选图源清单

详见同目录 `图片素材清单.md`（AI 维护：URL、内容、版权状态、是否已下载）
用户自有图片放入本目录后，请改名为规范命名，并在清单中补一行。
