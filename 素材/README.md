# 素材库总说明

项目：**歌未竟** —— 纪念毛泽东同志逝世五十周年网站（1976—2026）
网站主题语：久有凌云志，重上井冈山

## 目录结构

```
素材/
├─ 文字/
│  ├─ 诗词/    毛泽东诗词（公开本全收录），每首一个 .md 文件
│  ├─ 文章/    精选文章 10 篇，每篇一个 .md 文件
│  └─ README.md
├─ 图片/
│  ├─ 图片素材清单.md   候选图源 + 版权状态 + 下载记录
│  └─ （图片文件）按规范命名存放
├─ 音频/
│  └─ README.md   （音频由用户自行搜集放入此目录）
└─ README.md      本文件
```

## 文件命名规范

| 板块 | 规范 | 示例 |
|---|---|---|
| 文字/诗词 | `年份_词牌·篇名.md` | `1925_沁园春·长沙.md` |
| 文字/文章 | `年份_篇名.md` | `1944_为人民服务.md` |
| 图片 | `内容_来源.jpg` | `开国大典_新华社.jpg` |
| 音频 | `年份_篇名.mp3`（配乐加 `_bg` 后缀） | `1961_卜算子·咏梅.mp3`、`1961_卜算子·咏梅_bg.mp3` |

## 版权原则

1. 文本（诗词、文章）属于公开出版物，可正常使用，但**原文必须核对权威版本**；
2. 图片逐张标注来源与版权：官方发布（可标注用途使用）/ 公有领域 / 需授权（不建议直接使用）；
3. 音频由用户自备并自行确认版权，本站目录仅存档。

## 如何添加内容（"做好可以添加的准备"）

1. **加一首诗**：在 `文字/诗词/` 新建 `年代_篇名.md`，按现有文件模板写 front matter（标题/年代/体裁/版本/来源）+ `## 原文` + `## 名句` + `## 译文` + `## 背景`
2. **加一篇文章**：在 `文字/文章/` 新建 `年代_篇名.md`（front matter + 正文）
3. **加一张图**：放入 `图片/`，并在 `site/scripts/build-data.mjs` 的 `IMAGE_MAP` 中登记"篇名关键字 → 图片文件名"（不登记则只在图库出现）
4. **放入音频**：按 `音频/README.md` 命名规范放入，等播放功能接入
5. **入站**：在 `site/` 目录运行 `npm run build`，重新部署即可；本地预览 `local/` 运行 `npm run preview`
