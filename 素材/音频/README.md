# 音频板块（用户自备）

本目录由用户自行搜集放入，AI 不代收。

## 命名规范

```
年份_篇名.mp3         朗诵音频（如 1925_沁园春·长沙.mp3）
年份_篇名_bg.mp3      配乐（如 1961_卜算子·咏梅_bg.mp3）
```

## 每个"展播节点"需要的素材（可参差，缺的用自动兜底）

| 节点元素 | 优先（用户提供） | 兜底（AI 提供） |
|---|---|---|
| 配乐 | 本目录 `_bg.mp3` | 公版/可商用纯音乐按情绪匹配 |
| 朗诵 | 本目录 `.mp3` | AI 语音合成 / 纯音乐+文字浮现 |
| 图片 | 图片目录 | 纯色大字设计图 |
| 原文 | 文字目录 | 文字目录 |

## 建议

- 格式：mp3（推荐 128kbps+）或 m4a；
- 文件名中的篇名与文字目录保持一致，便于程序自动关联；
- 若同一个篇目有多版本（如不同朗诵者），加序号：`1925_沁园春·长沙_v2.mp3`。
